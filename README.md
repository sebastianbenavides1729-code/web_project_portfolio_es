# Portafolio personal — Sebastián Benavides

Sitio web de portafolio personal creado para presentar mi perfil como desarrollador Full-Stack Junior, mis habilidades y proyectos destacados.

## Descripción

El sitio incluye:

- Presentación profesional y breve descripción de perfil.
- Enlace para descargar el CV.
- Acceso al perfil de GitHub.
- Sección de habilidades y herramientas.
- Proyectos destacados.
- Información de contacto y redes sociales.
- Diseño responsive para distintos tamaños de pantalla.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Google Fonts
- Normalize.css
- Git y GitHub

## Estructura del proyecto

```text
├── images/        # Imágenes e íconos del sitio
├── styles/        # Archivos CSS por secciones
├── vendor/        # Dependencias CSS externas
├── index.html     # Página principal
└── README.md
```
